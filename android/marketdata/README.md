## marketdata

Android library with the exchange connectors: one class per exchange in `model/exchange/`, the shared base class `Exchange` in `model/`, and helpers (JSON, number formatting, currency symbols, bulk tickers) in `util/`. Add a new exchange here.

Step-by-step guide: [DEVELOPMENT.md](../../DEVELOPMENT.md) in the repository root. The iOS counterpart lives in `ios/Shared/Exchanges`. Project overview: [main README](/README.md).
