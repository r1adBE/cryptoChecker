ビットコインが指定した価格に達したらアラーム。実際に使っている取引所の価格で知らせます。平均値ではなく、あなたの取引所の価格。無料、アカウント不要。

ここが違う
• 平均ではなく、選んだ取引所：各行には、選んだ取引所でのそのペアの直近価格を表示します。Binance、Coinbase、Kraken、OKX、Bybit など多数に対応。
• 一度だけ知らせるアラーム：「BTC が 100,000 USDT を上回ったら知らせる」。更新のたびではなく、水準を超えたときに鳴ります。「1回」なら通知後にオフ、「毎回」なら価格が戻ると再びセットされます。
• 「一緒に動いているのは？」：コインごとの要因リスト（市場全体、出来高、ボラティリティ、Funding と Open Interest、高値・安値からの距離、Fear & Greed）。同じ時間に何が動いているかを示すもので、原因でもニュースでも投資助言でもありません。
• アカウントなし、広告なし、トラッキングなし。開発者があなたのデータを受け取ることはありません。

データについて正直に
• 初期設定は「省エネ」：アプリを開いたときと、バックグラウンドで一定間隔ごとに更新します。「開いている間ライブ」にすると、ウォッチリストを開いている間 Binance・Bybit・OKX・Coinbase・Kraken のライブ価格を表示します。
• 騰落率とチャートはまずペアの取引所から取得します。ローソク足がない場合は Binance または Coinbase を使い、その旨を表示します。
• 時価総額は CoinGecko、Fear & Greed・ドミナンス・オンチェーン指標は alternative.me、CoinGecko、Coin Metrics から（主にプロジェクト独自のデータミラー経由）。
• アプリを閉じているとき、アラームをいつ確認するかは Android が決めます。おおよそ15分ごと、実際にはそれより間隔が空くことも多く、その間の短い急変は捉えられないことがあります。アプリ内でもそうお知らせします。
• 金額は、自分で書き出さない限り（CSV、バックアップ）端末内に残ります。価格の取得で送るのはペアのティッカーだけで、送り先はそのペアの取引所です。ほかに為替レート（Frankfurter）、市場データとロゴ（CoinGecko、Binance）、データミラー（GitHub）を使います。アドレスや xpub を監視する場合、公開ブロックチェーンノードにアドレス（xpub では派生アドレス）とあなたの IP が見えます。

ウォッチリスト
• 32 の取引所で 41 の市場：現物と先物、DexScreener 経由の DEX トークン、必要なら株式・金・為替（TradFi）
• 2行目に「≈ 換算額」を 31 通貨（EUR、CHF、USD など）から表示（為替レートで換算）
• ミニチャートと、24 時間またはお住まいのタイムゾーンの 00:00 からの騰落率
• グループ、お気に入り、ドラッグで並べ替え、コインごとのメモ
• 「古いデータ」や「取引所に接続できません」を行に表示

アラーム
• 価格が水準を上回る・下回る、または一定の % 上昇・下落。換算通貨でも設定可（例：USDT ペアで 60,000 EUR）
• 一定時間内の x % の変動、出来高の急増
• サウンド（自分の音声ファイルも可）、バイブレーション、読み上げ（任意）
• おやすみ時間と「アラームをテスト」：アラームの届き方を事前に確認。アラーム履歴：確認した日時と価格、アラームが鳴らなかった理由

マーケット
• 異常な動き：ウォッチリスト内の普段と違う価格・出来高の動きを表示、通知も可
• Crypto Pulse、Fear & Greed、ビットコイン指標、Funding と Open Interest を数値のまま表示
• Ethereum、Bitcoin などのネットワーク手数料、ガスアラーム付き

そのほか
• ウィジェット：ウォッチリスト、ポートフォリオ合計、チャート付きの単一コイン
• ポートフォリオは任意（設定でオン）：購入、売却、スワップ、振替、リワード、入金・出金。FIFO（標準）または平均（Ø）。BTC（xpub 対応）、ETH と EVM チェーン、SOL、TRX、XRP、LTC、TON のアドレスを読み取り専用で登録（シード不要）。Relai・Swissquote・Bitpanda・Kraken・Binance・Coinbase の CSV を読み込み。年間まとめを CSV で出力。専用ロック付き。Bitpanda と Swissquote は公開の価格フィードがないためライブ価格は表示されません。取引は CSV で読み込みます。
• 誰でも読みやすく：緑/赤または青/オレンジ、色だけでなく符号と矢印。TalkBack は各行を 1 文で読み上げ
• ファイルへのバックアップと復元（Android と iPhone の間でも可）
• ライト／ダークモード、5 色のアクセントカラー、31 言語
• オープンソース（MIT）。コードは GitHub で公開

ご注意：Crypto Checker は価格と、ご自身で入力したポートフォリオを表示するアプリです。取引所やウォレットではなく、取引は行わず、投資助言も行いません。
